## 📌 公众号文章创作

### 1.1 标题规范

**叙事钩子型**（推荐）：
- 「I Did X for Y Days」（我做了X Y天）
- 痛点 + 解决方案 + 情绪词
- 具体数字 + 效果承诺

**禁止的标题类型**：
- ❌ 模板化：「如何」「技巧」「方法」
- ❌ 太泛：「互联网营销」「AI时代」
- ❌ 标题党过度：与内容严重不符

### 1.2 H2 结构要求

| 类型 | 要求 | 示例 |
|------|------|------|
| **叙事H2** | ≥ 2个 | moment/frustration/behavior change |
| **模板H2** | ≤ 1个 | 工具推荐/资源整理 |
| **对比模式** | Bad/Good | 错误做法 vs 正确做法 |

**禁止的H2模板**：
- ❌ Introduction / Conclusion / Summary
- ❌ Pros and Cons / Key Features
- ❌ What Is / How to Choose / FAQ

### 1.3 文章格式要求

```markdown
# 标题（叙事钩子型，避免模板化）

## 叙事H2（moment/frustration/behavior change）≥2个
正文内容...

## 另一个叙事H2
正文内容...

## 模板H2 ≤1个（可选）
正文内容...
```

### 1.4 公众号封面图标准

**❌ 低质量**：纯色背景+居中文字，无层次感

**✅ 高质量标准**：
- 渐变背景（不能是纯色平面）
- 科技感装饰元素（光晕、网格线、几何图形）
- 字体大小层次分明（主标题58-70px，副标题32-40px）
- 底部标签区域（带底色块+文字）
- 左侧装饰条或右上角光晕点缀

## 📕 小红书图文创作

### 2.1 标题规范

**核心公式**：
```
人群 + 场景 + 痛点 + 解决方案 + 情绪词
```

**标题示例**：
- "😭终于有人把XXX说清楚了！新手必看"
- "这5个XXX技巧，后悔没早点知道"
- "避坑指南｜XXX千万不要踩的坑"

### 2.2 9张轮播图规范

| 序号 | 内容 | 视觉风格 |
|------|------|---------|
| 1 | 封面图 | 科技感渐变，震撼大字 |
| 2 | 为什么选这个组合 | 两列对比卡片 |
| 3 | 准备工作 | 图标+文字卡片 |
| 4 | Step 1 安装 | 终端窗口模拟 |
| 5 | Step 2 配置 | 命令行+警告框 |
| 6 | Step 3 验证 | 对话模拟+成功提示 |
| 7 | 避坑指南 | ❌问题 → ✅解决 |
| 8 | 能做什么 | 四宫格能力展示 |
| 9 | 结尾页 | 深色背景+关注引导 |

**技术规格**：
- 尺寸：1080x1080（正方形）
- 字体：STHeiti Medium（标题）/ STHeiti Light（正文）
- 页码：右下角圆形徽章 "X/9"

### 2.3 表情符号使用规范

- 开头用 🔥💯✅❌🆘🎉 等吸引眼球
- 段落间用 ➡️💡⚠️📌✅❌ 分隔
- 结尾用 💬👇🙋‍♀️👍❤️📢 收尾

## 🎨 配图规范

### 4.1 公众号封面图

```python
from PIL import Image, ImageDraw, ImageFont

W, H = 900, 383
img = Image.new('RGB', (W, H), '#0a1628')
draw = ImageDraw.Draw(img)

# 渐变背景
for y in range(H):
    ratio = y / H
    r = int(10 + ratio * 30)
    g = int(22 + ratio * 40)
    b = int(40 + ratio * 80)
    draw.line([(0, y), (W, y)], fill=(r, g, b))

# 装饰性网格线（科技感）
for i in range(0, W, 60):
    draw.line([(i, 0), (i, H)], fill=(255,255,255,15))

# 主标题（58-70px，居中）
title_font = ImageFont.truetype('/System/Library/Fonts/STHeiti Medium.ttc', 58)
title = "主标题"
draw.text(((W - 300) // 2, 80), title, fill='white', font=title_font)

img.save('cover.png', quality=95)
```

### 4.2 配图质量标准

| 要求 | 说明 |
|------|------|
| **内容贴合** | 配图元素必须与文章内容一致 |
| **中文优先** | 有文字必须是中文，不能有英文 |
| **互联网风格** | 现代扁平设计，避免水墨/古典风格 |
| **无中西差异** | 避免西方宗教元素、欧美面孔 |
